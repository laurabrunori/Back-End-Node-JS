# Back-End-Node-JS
# Preentrega Node.js - Gestión de Productos

## Descripción

Este proyecto corresponde a la preentrega del curso de Node.js. Consiste en una aplicación de consola que permite realizar operaciones de consulta, creación y eliminación de productos mediante peticiones HTTP a la API [DummyJSON](https://dummyjson.com/docs/products).

La aplicación interpreta los comandos ingresados desde la terminal y ejecuta la operación correspondiente sobre los productos.

## Tecnologías utilizadas

* **Node.js:** entorno de ejecución de JavaScript.
* **npm:** administrador de paquetes.
* **JavaScript ESModules:** configuración mediante `"type": "module"`.
* **Fetch API:** para realizar peticiones HTTP.
